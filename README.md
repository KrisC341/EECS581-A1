# EECS581-A1-Extracting-IPv4-Addresses-from-Noisy-Text
This repository serves as a submission for EECS581 Assignment 1, where we are asked to 'Write a C or C++ program that reads a line of text and extracts a single valid IPv4 address — optionally followed by a port number — embedded anywhere in that text.'. 

According to the assignment description provided, there are two goals to this assignment: 'The first is technical: develop proficiency in C/C++ string parsing and validation of structured, numeric-like data embedded in unstructured text. The second is professional and is the primary point of this exercise: develop and demonstrate disciplined use of generative AI (GAI) tools in software development'. 

Almost all of the code written in this repository was generated using Google Gemini 3.1 Pro. Further details can be found in the AI Disclosure documentation. 

The program can be run by typing './A1' into the terminal when viewing this repository.
